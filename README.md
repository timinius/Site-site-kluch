# WEB.EKB: сайт студии

Статический сайт без сборки: HTML, CSS и JavaScript. Подходит для GitHub Pages, Netlify и любого хостинга.

## Перед публикацией

1. **Подключите форму заявок** (без этого заявки не уходят, и посетитель видит ошибку):
   - **GitHub Pages или любой хостинг.** Получите бесплатный ключ на [web3forms.com](https://web3forms.com): укажите почту, ключ придёт письмом. Вставьте его в `js/main.js`, в `FORM_CONFIG.web3formsKey`. Заявки будут приходить на эту почту.
   - **Netlify.** В `js/main.js` поставьте `provider: 'netlify'`. Форма уже размечена для Netlify Forms, ключ не нужен.
   - **Хостинг с PHP (Beget, Timeweb и т. п.).** Поставьте `provider: 'php'`, скопируйте `send-config.example.php` в `send-config.php` и впишите токен Telegram-бота и/или почту.
2. **Заполните политику конфиденциальности** в `privacy.html`: поля, подсвеченные медным фоном (оператор, ИНН, почта, дата).
3. **Укажите полный адрес картинки для соцсетей.** В `<meta property="og:image">` в `index.html` и `portfolio.html` замените `img/og.jpg` на полный адрес, например `https://ваш-домен.ru/img/og.jpg`.
4. **Контакты.** На сайте нет телефона и Telegram, потому что их не было в исходной версии. Если хотите показать их, добавьте в подвал и в блок заявки.

## Структура

- `index.html`: главная. Первый экран — малахитовая дверь: при прокрутке ключ поворачивается, створки открываются и показывают стену работ.
- `portfolio.html`: все работы с фильтром по типам и просмотром.
- `privacy.html`: политика конфиденциальности.
- `404.html`: страница «Ключ не подошёл».
- `css/style.css`: все стили. Цвета и размеры заданы переменными в начале файла.
- `js/main.js`: общий скрипт (дверь, меню, форма). `js/works.js`: фильтр и просмотр на странице работ.
- `fonts/`: Sofia Sans и Sofia Sans Extra Condensed (лицензия SIL OFL). В кириллические файлы добавлен знак ₽, которого нет в исходном шрифте.
- `img/works/`: работы в WebP (`NN.webp` целиком, `NN-640.webp` превью). `img/wall/`: фрагменты работ для стены на главной.
- `send.php`: обработчик заявок для PHP-хостинга (по желанию).

## Как добавить работу

1. Сохраните изображение в WebP: целиком (`img/works/31.webp`, ширина около 1200 px) и превью шириной 640 px (`img/works/31-640.webp`).
2. Скопируйте любой блок `<figure class="gallery__item">` в `portfolio.html`, поменяйте пути, размеры, подпись и `data-tags`: `stories`, `previews`, `banners`, `posts`, `logos`.
3. Обновите число в кнопке фильтра.

## Если сайт лежит не в корне домена

Страница `404.html` ведёт на `/`. Если сайт открывается по адресу вида `username.github.io/repo/`, поправьте ссылку «На главную» в `404.html`.
